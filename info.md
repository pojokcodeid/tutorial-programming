## Topik Contoh Project React JS

Materi proyek praktis membangun satu aplikasi React lengkap (Dashboard Toko):
custom component, routing, Context API, axios, dummy backend, authentication &
authorization, hingga access & refresh token otomatis, dengan component library
Ant Design. Berdiri sebagai tutorial terpisah dengan kuis tersendiri; kode
project nyata ada di folder `examples/react-project/`.

- Rujukan
  - https://react.dev/learn
  - https://ant.design/
  - https://reactrouter.com/
  - https://axios-http.com/docs/intro
  - https://github.com/typicode/json-server

- Materi yang harus ada

1. Fondasi Proyek
   - Pengenalan & Setup Proyek: gambaran fitur, perpustakaan yang dipakai (React + Vite, Ant Design, React Router DOM, Axios, json-server, JWT), struktur folder, dan menjalankan frontend + backend berdampingan.
   - json-server sebagai Dummy Backend: db.json (users, products, refreshTokens), json-server programatik lewat server.js, endpoint auth (register, login, refresh, logout, me), middleware authenticate & requireRole, serta aturan akses resource.
2. Komponen & Navigasi
   - Custom Component dengan Ant Design: komponen presentasional (PageHeader, StatCard), membungkus Table Ant Design menjadi ProductTable, layout AppShell dengan menu berbasis peran.
   - Routing dengan React Router DOM: peta rute App.jsx, nested route + Outlet, layout route, ProtectedRoute dengan Navigate state, rute dinamis useParams, useNavigate & useLocation, halaman 404.
3. State & HTTP
   - Context API: masalah prop drilling, AuthContext + custom hook useAuth, pemulihan sesi, jembatan event "sesi berakhir" dari axios.
   - Axios: instance dengan baseURL, interceptor request (header Authorization), modul API terpisah (authApi, productApi, userApi), pola loading & error di halaman.
4. Keamanan
   - Authentication & Authorization: form login/register dengan validasi Ant Design, penyimpanan token, ProtectedRoute & RoleGate, otorisasi di sisi tampilan beserta batasannya.

## Topik Lucee CFML

- Rujukan
  - https://rorylaitila.gitbooks.io/lucee/content/
  - https://docs.lucee.org/index.html

- Materi yang harus ada

1. Fondasi & Dasar-Dasar CFML (Beginner)
   - Pengenalan Ecosystem & Setup Environment
     - Apa itu CFML (ColdFusion Markup Language) dan keunggulan Lucee (Open Source & High Performance).
     - Instalasi Lucee Server lokal menggunakan CommandBox (box server start).
     - Pemahaman arsitektur dasar Lucee yang berjalan di atas JVM (Java Virtual Machine).
     - Setup Code Editor (Neovim / VS Code) dengan extension CFML / CFLint.
   - Sintaks Dasar CFML (Tag-based vs CFScript)
     - Perbedaan sintaks Tag-based (<cfset>, <cfif>) dan CFScript (sintaks mirip JavaScript/Java).
     - Variabel dan Tipe Data: String, Number, Boolean, Date.
     - Variabel Scopes dasar: variables, arguments, local, session, application, request.
     - Struktur Kontrol: Conditional (if/else, switch/case) dan Looping (for, while, cfloop).
   - Data Structures & Manipulasi Data
     - Arrays: Deklarasi, manipulasi, serta fungsi bawaan (arrayAppend, arrayLen, arrayMap, arrayFilter).
     - Structures (Struct): Key-value pair, manipulasi struct, dan nested struct.
     - Queries: Konsep data query bawaan CFML.

2. Pengolahan Data & Pemrograman Menengah (Intermediate)
   - Interaksi Database (SQL & ORM)
     - Koneksi Database via Lucee Admin atau file konfigurasi Application.cfc (Datasource setup).
     - Mengabaikan Vulnerability: Menggunakan <cfquery> dengan <cfqueryparam> (Pencegahan SQL Injection).
     - Operasi CRUD (Create, Read, Update, Delete).
     - Dasar-dasar Lucee ORM (Hibernate integration) untuk pemetaan objek database.

   - Modularisasi & Reusability
     - User Defined Functions (UDF): Deklarasi fungsi, argumen, return type, dan scope lokal (local).
     - ColdFusion Components (CFC): Konsep dasar class/component, properti, method (cffunction), dan akses modifier (public, private, package).
     - Penggunaan cfinclude dan cfmodule secara efisien.

   - Konfigurasinya & Lifecycle Aplikasi (Application.cfc)
     - Memahami struktur dan lifecycle event di Application.cfc:
     - onApplicationStart()
     - onRequestStart() / onRequestEnd()
     - onSessionStart() / onSessionEnd()
     - onError()
     - Pengelolaan Session Management dan Cookies.

3. Arsitektur Modern & Lanjutan (Advanced)
   - Object-Oriented Programming (OOP) di CFML
     - Konsep Encapsulation, Inheritance, Polymorphism, dan Interfaces di CFC.
     - Dependency Injection & Inversion of Control (IoC) menggunakan framework seperti WireBox.
     - Design Patterns dasar dalam CFML (DAO, Gateway, Factory, Singleton).

   - Pengembangan RESTful API & Web Services
     - Membuat REST API native di Lucee menggunakan annotation pada CFC (restpath, httpmethod).
     - Penanganan request/response JSON & XML (serializeJson, deserializeJson).
     - Otentikasi dan Otorisasi API (JWT / Token-based Authentication).

4. Performa, Deployment, & Profesional (Expert / Senior)
   - Lucee Administration & Configuration Management
     - Pengelolaan Lucee Web Admin dan Server Admin.
     - Konfigurasi berbasis kode/environment (lucee-web.xml.cfm, Application.cfc settings, environment variables).
     - Pengaturan Cache Engine (Redis, Ehcache, Memcached) untuk optimasi query dan page caching.

   - Integrasi Java & Sistem Eksternal
     - Interoperabilitas Java: Memanggil class Java eksternal atau JAR library langsung dari CFML (CreateObject("java", ...) / JavaCast).
     - Penanganan operasi asinkron: cfthread, Task Scheduling, dan Event Gateways.
     - File Management & Document Processing (PDF Generation via cfdocument, Spreadsheet via Apache POI / cfspreadsheet).

   - Testing & Code Quality
     - Unit Testing dan Integration Testing menggunakan TestBox.
     - Static Code Analysis & Linting menggunakan CFLint.
     - Logging dan Error Monitoring/Tracking (Sentry, LogBox, custom exception handling).

   - DevOps, Deployment, & Security - Deployment menggunakan Docker container & CommandBox Docker Images.

   - Cluster RabbitMQ (Erlang cookie, join_cluster), quorum queue (Raft) vs mirrored queue (legacy).
   - Federation (upstream-downstream, exchange-to-exchange) & shovel (queue-to-remote, ack-mode on-confirm).
6. Keamanan & Monitoring (Phase 7)
   - User, vhost, permission (configure/write/read) dengan pola regex; TLS (port 5671, amqps).
   - Monitoring: plugin `rabbitmq_prometheus`, endpoint `/metrics`, Prometheus + Grafana, metrik kunci & alarm.
7. Production Readiness & Praktik Proyek
   - Tuning: publisher confirm, watermark memori, disk limit, heartbeat; anti-pattern yang harus dihindari.
   - Proyek 1: worker queue sederhana (publisher, antrean durable, worker dengan ACK & prefetch).
   - Proyek 2: publisher-subscriber (fanout) dengan retry & dead letter queue.
   - Proyek 3: graceful shutdown — cancel consumer, selesaikan yang berjalan, tutup channel & koneksi.

## Topik Dasar RESTful API

Materi **Dasar RESTful API** — bab terpisah untuk pemula total yang baru mengenal dunia backend dan API — disusun dalam 15 pelajaran berbahasa Indonesia dengan kuis 40 soal. Cakupannya mengikuti roadmap `roadmap-belajar-restful-api.md` Fase 1 sampai Fase 3 (dengan pengantar Fase 4 berupa proyek mini), tanpa mengulang materi HTTP mendalam (cookie, cache, CORS, HTTPS) yang sudah dibahas di materi HTTP. Penjelasan memakai analogi sehari-hari (restoran, surat, antrean, struk) agar mudah dipahami orang awam, dilengkapi latihan interaktif "Coba sendiri" yang berjalan offline.

- Rujukan
  - https://restfulapi.net/
  - https://developer.mozilla.org/en-US/docs/Web/HTTP
  - https://jsonplaceholder.typicode.com/
  - https://pokeapi.co/
  - https://learning.postman.com/

- Materi yang harus ada

1. Apa Itu API? Kenapa Aplikasi Butuh API
   - Analogi restoran, perantara resmi dua program, perbedaan website dengan API, aktivitas harian yang memakai API.
2. Client, Server, Request, dan Response
   - Anatomi request (method, URL, header, body) dan response (status, header, body), analogi surat, pengamatan lewat DevTools Network.
3. URL dan Endpoint: Alamat Rumah untuk Data
   - Anatomi URL (skema, domain, path, query), endpoint sebagai URL + method, DNS/IP singkat, penamaan berbasis kata benda.
4. HTTP Method: GET, POST, PUT, PATCH, DELETE
   - Pemetaan CRUD ke method, tabel endpoint + status sukses, HEAD/OPTIONS, aturan method = aksi dan path = resource.
5. Status Code: Kode Balasan Server
   - Kelompok 2xx/3xx/4xx/5xx, kode yang paling sering muncul, 401 vs 403, mengapa API tidak boleh selalu membalas 200.
6. Mengenal JSON: Bahasa Data Web
   - Objek, array, pasangan kunci-nilai, JSON bersarang, kenapa JSON mendominasi API modern, perbandingan singkat dengan XML.
7. Path, Query, dan Body: Di Mana Data Diletakkan
   - Path = menunjuk resource, query = mengatur cara membaca (filter/halaman), body = isi data, larangan menaruh rahasia di query.
8. HTTP Headers: Amplop yang Menyimpan Instruksi
   - Content-Type, Accept, Authorization, User-Agent, Cache-Control; membaca header di DevTools dan Postman.
9. Apa Itu REST? Enam Prinsipnya
   - REST karya Roy Fielding (2000), client–server, stateless, cacheable, uniform interface, layered system, code on demand.
10. Merancang Endpoint yang Enak Dibaca
    - Kata benda jamak, kebab-case, resource bersarang maksimal 2–3 level, versi /api/v1, tabel endpoint contoh toko.
11. Format Response dan Error yang Konsisten
    - Contoh respons sukses dan gagal, pesan error yang aman dan jelas, field bantu meta untuk daftar data.
12. Safe, Idempotent, dan Kesalahan Desain yang Sering Terjadi
    - Safe (GET/HEAD/OPTIONS), idempotent (GET/PUT/DELETE), POST tidak idempotent, kesalahan umum desain endpoint.
13. Mencoba API Sungguhan: Postman dan cURL
    - Anatomi request di Postman, perintah cURL, API publik latihan (JSONPlaceholder, PokéAPI, ReqRes), menangani 404/500/koneksi putus.
14. Memanggil API dari Program
    - Fetch API, Axios, requests (Python), pemeriksaan res.ok/status_code, penanganan error, pengantar asynchronous.
15. Proyek Mini dan Rangkuman
    - Rangkuman seluruh bab, Proyek Mini A konsumsi API publik, Proyek Mini B perancangan API toko, checklist lanjut ke Fase 4.

## Topik Mengenai GraphQL

Materi **GraphQL** — bahasa query untuk API yang membebaskan klien menentukan persis data yang dibutuhkan — disusun dalam 15 pelajaran berbahasa Indonesia lengkap dengan contoh kode, latihan simulasi interaktif, tip, peringatan, kosakata, dan kuis 46 soal. Materi mengikuti roadmap `roadmap_belajar_graphql.md` (Fase 1–6) dan plan `plan/belajar_graphql.md`, dari konsep dasar hingga arsitektur microservices. Praktik backend memakai **Node.js + Apollo Server + Prisma + MariaDB** dengan koneksi `localhost:3306` (user `root`, password `rootpassword`), frontend memakai React + Apollo Client dengan normalized cache dan GraphQL Code Generator.

- Rujukan
  - https://graphql.org/
  - https://www.apollographql.com/docs/
  - https://www.prisma.io/docs/
  - https://the-guild.dev/graphql/yoga-server
  - https://odyssey.apollographql.com/
  - https://the-guild.dev/graphql/codegen

- Materi yang harus ada

1. Konsep Dasar (Fase 1)
   - Pengenalan GraphQL: sejarah di Facebook (2012) hingga open source (2015), masalah over-fetching & under-fetching REST, perbandingan REST vs GraphQL, satu endpoint vs banyak endpoint, kapan memilih masing-masing.
   - Tiga operasi GraphQL: Query (baca), Mutation (ubah), Subscription (real-time via WebSocket) beserta karakteristik masing-masing.
2. Sintaksis Klien (Fase 2)
   - Menulis query: selection sets, arguments, aliases (hindari konflik nama field), fragments (reuse field group).
   - Mutation & variables: anti-pattern nilai hardcode vs best practice variabel, input types untuk argument, directives @include dan @skip untuk query kondisional.
3. Membangun GraphQL Server (Fase 3)
   - Schema SDL: scalar types, custom types, enums, input types, non-null (!) dan lists, contoh schema lengkap blog (User, Post, Comment).
   - Resolvers: fungsi (parent, args, context, info), execution flow per level, context sebagai "tas belanja" bersama, pengantar N+1 problem.
   - Setup server dengan Apollo Server + Prisma + MariaDB: struktur folder, tsconfig, .env DATABASE_URL (mysql://root:rootpassword@localhost:3306/graphql_db), schema.prisma model User & Post, SDL, resolver CRUD, seed, migration & menjalankan server.
   - Pagination (limit/skip), filtering (input type), sorting (enum), dan cursor-based pagination bergaya Relay (edges, node, pageInfo).
4. Frontend Integration (Fase 4)
   - Integrasi Apollo Client di React (Vite): konfigurasi InMemoryCache + HttpLink, ApolloProvider, useQuery dan useMutation, refetchQueries.
   - Normalized cache (__typename + id) dan GraphQL Code Generator untuk tipe TypeScript otomatis.
5. Teknik Lanjutan (Fase 5)
   - N+1 problem beserta ilustrasi query berulang dan solusi DataLoader (batching + caching per request).
   - Keamanan: autentikasi JWT lewat context, otorisasi level resolver (401 vs 403), directive kustom @auth/@hasRole, depth limit, complexity limit, rate limiting, mematikan introspeksi di produksi.
   - GraphQL Subscriptions real-time: tipe Subscription di SDL, PubSub publish/subscribe, konfigurasi graphql-ws di Apollo Server v4, useSubscription + split link di klien, catatan scaling dengan Redis PubSub.
6. Arsitektur Skala Besar (Fase 6)
   - Schema Stitching vs Apollo Federation: supergraph, subgraph, @key directive, entity reference (__resolveReference), gateway menggabungkan query plan; kapan memakai Federation vs tetap monolitik.
7. GraphQL dengan Go (bab tambahan)
   - Membangun server GraphQL dengan Go: perbandingan library (GQLGen, graphql-go, graph-gophers), inisialisasi proyek (go mod init, gqlgen init), penulisan schema.graphqls, code generation (gqlgen generate), koneksi GORM ke MariaDB (DSN root:rootpassword@tcp(localhost:3306)/blog_go?parseTime=True), implementasi resolver Query & Mutation (posts, post, users, createPost, publishPost), server main.go dengan Playground, pengujian lewat cURL, alur request lima tahap, serta peringatan file generated tidak boleh diedit manual.
