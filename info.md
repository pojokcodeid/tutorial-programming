# Aplikasi Web App Tutorial Programming

## Fitur

- Terdapat materi multiple Tutorial seperti html, css,javascript,typescript ,dll
- Dalam setiap materi ada subjudul di sidebar
- setiap materi di jelaskan dalam bahasa indonesia yang sederhana dan mudah di
  mengerti
- setiap bahasan atau topik ada contoh contohnya yang codenya sudah ada
  pewarnaannya
- di bagian akhir materi ada kuis yang berhubungan dengan materi yang isi
  pertanyaan dan jawaban selalu berubah jika di buka di lain waktu atau masih salah
- user bisa login dan tersimpan history pembelajarannya
- materi pembelajaran bersipat terpadu atau tahap demi tahap
- tutorial dapat dijalankan secara ofline
- tutorial dapat di jalankan secara portable

## Teknologi

- Tutorial ini menggunakan html css dan javascript
- library yang digunakan bebas yang penting opensource

## Topik Mengenai React JS

- Rujukan
  - https://react.dev/learn
  - https://www.w3schools.com/react/default.asp
  - https://www.javascripttutorial.net/react-tutorial/

- Topik harus dibahas
  - Pengenalan React: Apa itu SPA (Single Page Application), konsep Virtual DOM, dan mengapa menggunakan React.
  - Setup Project: Menggunakan Vite atau Create React App.
  - JSX (JavaScript XML)
    - Aturan penulisan JSX.
    - Embedded expressions di dalam JSX.
  - Components & Props:
    - Functional Components.
    - Mengirim dan menerima data antar komponen menggunakan Props.
  - Styling di React:
    - Inline CSS, CSS Modules, atau Tailwind CSS.
  - Basic State & Event Handling:
    - Mengenal useState Hook untuk mengelola data lokal komponen.
    - Menangani event seperti onClick, onChange, dll.
  - Conditional Rendering & Lists:
    - Operator ternary dan logical &&.
    - Merender data array menggunakan method .map() dan penggunaan key.
  - React Hooks Esensial:
    - useEffect: Menangani side effects (fetching data, manipulasi DOM manual).
    - useRef: Mengakses elemen DOM secara langsung dan menyimpan nilai tanpa re-render.
    - useMemo & useCallback: Optimasi performa dasar (memoization).
  - Form Handling di React:
    - Controlled vs Uncontrolled components.
    - Validasi form sederhana atau menggunakan library seperti React Hook Form + Zod / Yup.
  - Routing (Navigasi Antar Halaman):
    - Menggunakan React Router DOM (Dynamic routes, Nested routes, useNavigate, useParams).
  - Global State Management (Dasar):
    - Context API: Mengirim data lintas komponen tanpa prop drilling.
  - Advanced State Management:
    - Library state management modern seperti Zustand, Redux Toolkit, atau TanStack Query (React Query) untuk server state & caching.
  - Performance Optimization:
    - Code Splitting & Lazy Loading menggunakan React.lazy() dan Suspense.
    - Mencegah re-render yang tidak perlu.
  - Custom Hooks:
    - Membuat logika yang dapat digunakan kembali (reusable logic) dalam bentuk Custom Hook sendiri.
  - Testing di React:
    - Unit testing & component testing menggunakan Jest dan React Testing Library (RTL).
  - TypeScript dengan React:
    - Memberikan tipe data pada Props, State, useRef, dan Event handlers untuk keamanan kode (Type Safety).
  - Mengenal Ekosistem Full-Stack / Framework Modern:
    - Transisi dari Client-Side Rendering (CSR) murni ke Next.js (Server-Side Rendering, App Router, SEO Optimization).

## Topik Mengenai GO-LANG

- Rujukan
  - https://www.gotutorial.org/
  - https://go.dev/doc/tutorial/
  - https://www.w3schools.com/go/index.php

- Topik harus dibahas
  - Pengenalan & Setup Lingkungan Kerja
    - Apa itu Go? (Kelebihan, kasus penggunaan, dan filosofi Go)
    - Instalasi Go & Konfigurasi Environtment Variables (GOROOT, GOPATH)
    - Mengenal Go Modules (go mod init, go mod tidy)
    - Memahami struktur folder dan file .go
    - Program pertama: Hello World & perinah go run, go build
  - Dasar-Dasar Bahasa Go
    - Variables & Constants: var, const, short variable declaration (:=)
    - Tipe Data Dasar: int, float, string, bool
    - Zero Values di Go
    - Type Conversion (Konversi tipe data)
    - Operator: Aritmatika, Perbandingan, dan Logika
  - Control Flow (Alur Kontrol)
    - Branching: if, else if, else
    - Switch Case: Standard switch, type switch, dan fallthrough
    - Looping: for loop (Go hanya memiliki satu jenis perulangan: for)
  - Tipe Data Koleksi & Komposisi
    - Array: Definisi, inisialisasi, dan keterbatasannya
    - Slice: Konsep underlying array, len(), cap(), append(), dan copy()
    - Map: Tipe key-value, manipulasi data map, dan pengecekan keberadaan key
    - Iterasi: Menggunakan for range pada Slice dan Map
  - Fungsi (Functions)
    - Deklarasi fungsi dan parameter
    - Multiple Return Values
    - Named Return Values
    - Variadic Functions (parameter tak terbatas)
    - Anonymous Functions & Closures
  - Pointer & Struct
    - Pointer: Mengerti alamat memori (&) dan dereferencing (*)
    - Pass by Value vs Pass by Reference
    - Struct: Definisi, nested struct, dan anonymous struct
    - Struct Method: Value Receiver vs Pointer Receiver
  - Interface & Type System
    - Konsep Implicit Interface di Go
    - Empty Interface (interface{} / any)
    - Type Assertion & Type Switches
  - Error Handling & Control Structures Khusus
    - Pengelolaan error menggunakan interface error
    - Membuat Custom Error
    - Penggunaan defer untuk cleanup resource
    - Penggunaan panic dan recover (kapan harus digunakan dan dihindari)
  - Package & Module Management
    - Membuat dan mengorganisir kustom package (Public vs Private / Exported vs Unexported identifier)
    - Mengelola dependency dengan go.mod dan go.sum
    - Mengunduh package pihak ketiga (go get)
  - Concurrency Dasar
    - Konsep Asynchronous & Parallelism
    - Goroutines: Menjalankan fungsi secara eksekusi concurrent (go keyword)
    - Channels: Send, receive, buffered vs unbuffered channel
    - Select Statement: Menerima data dari banyak channel
  - Concurrency Lanjutan & Sync Package
    - sync.WaitGroup untuk sinkronisasi Goroutine
    - sync.Mutex & sync.RWMutex untuk mencegah Race Condition
    - sync.Once & sync.Map
    - Menggunakan tools detector: go run -race
    - Context Package (context): Timeout, Cancellation, dan Passing Values
  - Testing & Benchmarking
    - Unit Testing dasar dengan package testing (go test)
    - Table-Driven Tests
    - Mocking & Interface Stubbing
    - Benchmark Testing (testing.B) & Code Coverage analysis
  - I/O, File System, dan Data Format
    - Package io, os, bufio, dan bytes
    - Membaca dan menulis file
    - Working with JSON, XML, dan CSV (encoding/json)
  - Web Development & REST API
    - HTTP Server dasar menggunakan net/http
    - Routing / Multiplexer (Standard Library vs Framework seperti Gin, Echo, atau Fiber)
    - Middleware pattern
    - Integrasi Database (SQL dengan database/sql, ORM seperti GORM atau SQL Builder seperti sqlx / sqlc)
    - Validasi request payload
  - Software Architecture & Best Practices
    - Clean Architecture / Hexagonal Architecture di Go
    - Dependency Injection (menggunakan library seperti google/wire atau manual)
    - Design Patterns populer di Go
  - Microservices & Distributed Systems
    - gRPC & Protocol Buffers (protobuf)
    - Message Broker integration (RabbitMQ, Apache Kafka, NATS)
    - Distributed Tracing (OpenTelemetry) & Centralized Logging (Zap/ZeroLog)
  - Advanced Go Internal & Optimization
    - Reflection (reflect package) & Unsafe Pointer
    - Memory Management: Garbage Collection (GC) tuning, Stack vs Heap allocation
    - Profiling & Performance Tuning: Menggunakan pprof dan trace
    - Generic programming (Generics di Go 1.18+)
  - DevOps, Deployment & Security
    - Containerization menggunakan Docker (Multi-stage build untuk binary yang kecil)
    - CI/CD Pipeline untuk project Go
    - Security best practices (mencegah SQL Injection, sanitasi input, CORS, JWT Auth)
