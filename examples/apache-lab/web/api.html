api.local

Virtual host API pada port 8080 — dipilih lewat header Host

Endpoint

  • /api/ — reverse proxy ke balancer backend-1/2/3
  • /api/headers/ — memantulkan header yang diteruskan Apache
  • /app/ — route aplikasi ke balancer yang sama
curl -H "Host: api.local" http://localhost:8080/
curl http://localhost:8080/api/headers/

Path di luar daftar di atas menghasilkan 404 (vhost API tidak memakai fallback SPA).
