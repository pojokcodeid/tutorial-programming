apache-lab — Gateway Aplikasi

Halaman statis dari /usr/local/apache2/htdocs (vhost app.local)

Rute yang tersedia

  • /docs/ — dokumentasi (dilayani dengan Alias, di luar DocumentRoot)
  • /private/ — diblokir (403, <Location> + Require all denied)
  • /api/ — reverse proxy ke load balancer backend-1/2/3
  • /app/ — reverse proxy (aplikasi) ke balancer yang sama
  • /halaman/tentang — contoh rute SPA (fallback ke index.html)
  • /server-status — mod_status (monitoring)
  • /server-info — mod_info (daftar modul & konfigurasi)

Request berekstensi yang tidak ada tetap 404, mis. /assets/hilang.css.

Virtual host

Coba kirim header Host berbeda ke port 8080:

  • Host: app.local (atau tanpa override) — halaman ini
  • Host: api.local — vhost API
  • Host: docs.local — vhost dokumentasi
curl -H "Host: api.local" http://localhost:8080/

HTTPS

Sertifikat self-signed tersedia di port 8443 (HTTP/2 aktif):

curl -k --http2 https://localhost:8443/

Port 8081 hanya melakukan redirect 301 ke https://localhost:8443/.
