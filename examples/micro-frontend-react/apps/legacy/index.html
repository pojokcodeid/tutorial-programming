Katalog versi lama

Halaman ini sengaja dibiarkan sebagai aplikasi statis di origin terpisah. Shell memuatnya lewat iframe di rute /katalog-lama. Inilah titik awal migrasi bertahap: pindahkan satu rute ke remote baru, lalu hapus rute lama setelah yakin tidak ada tautan yang tertinggal.

Memuat produk…

Batasan yang terlihat: halaman ini tidak berbagi state keranjang, token, tema, atau router dengan shell. Komunikasi hanya lewat postMessage atau URL. Itu sebabnya migrasi ke remote lebih nyaman begitu alurnya stabil.
