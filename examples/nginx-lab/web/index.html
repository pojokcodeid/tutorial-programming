nginx-lab — Gateway Aplikasi

Halaman statis dari /usr/share/nginx/html (server app.local)

Rute yang tersedia

  • /docs/ — dokumentasi (dilayani dengan alias)
  • /private/ — diblokir (403)
  • /api/ — reverse proxy ke upstream backend-1/2/3
  • /app/ — reverse proxy (aplikasi) ke upstream yang sama
  • /halaman/tentang — contoh rute SPA (fallback ke index.html)

Virtual host

Coba kirim header Host berbeda ke port 8080:

  • Host: app.local — halaman ini (default server)
  • Host: api.local — vhost API
  • Host: docs.local — vhost dokumentasi

Latihan

Jalankan skrip pengujian dari folder lab:

scripts/test-routing.sh
scripts/test-proxy.sh

Lab belajar Nginx — hanya untuk latihan, bukan untuk produksi.
