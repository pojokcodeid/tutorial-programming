Teknik 03 · Import map

Modul remote tanpa bundler.

Shell memetakan nama @lab/remote ke berkas /import-map/remote.js, lalu memanggil import('@lab/remote') saat tombol ditekan. Tidak ada bundler, tetapi juga tidak ada isolasi gaya atau global scope.

Shell

Kontrol pemuatan modul dan keranjang.

idle

Remote belum dimuat. Klik “Muat remote” untuk memulai.

Import map yang dipakai halaman ini:

<script type="importmap">
{
  "imports": {
    "@lab/remote": "/import-map/remote.js"
  }
}
</script>

Panggilan di shell: await import('@lab/remote')

    Belum ada modul yang dipasang.

    Klik Muat remote. Shell akan mengimpor modul secara dinamis, menampilkan status memuat, lalu memasang hasilnya ke slot ini.

    Yang perlu kamu amati

    • Status berubah dari idle ke memuat, lalu siap atau gagal.
    • Tombol “Coba modul rusak” memicu error, tetapi shell tetap hidup.
    • Modul remote berbagi dokumen yang sama — tidak ada Shadow DOM atau iframe.
