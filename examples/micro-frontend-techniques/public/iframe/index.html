Teknik 01 · iframe

Isolasi total, komunikasi terbatas.

Shell dan remote hidup di dua dokumen terpisah. Remote memakai tema terang dan font serif, sementara shell tetap gelap — CSS keduanya tidak saling bocor. Harga yang kamu bayar adalah komunikasi: semua pesan harus melewati postMessage.

Shell — dokumen induk

Kirim pesan ke remote, lalu lihat balasannya di log.

window.parent

Shell mengirim ke iframe.contentWindow dengan targetOrigin = '*'. Remote berjalan di dalam sandbox tanpa allow-same-origin, sehingga origin-nya menjadi opaque (null).

Remote — di dalam iframe

Dokumen ini punya CSS, global scope, dan siklus hidup sendiri.

sandbox="allow-scripts"

Tinggi iframe ditentukan shell (740 px di layar lebar, 580 px di layar kecil). Remote tidak bisa mengubah layout halaman induk, dan shell tidak bisa membaca DOM remote.

Yang perlu kamu amati

Isolasi bekerja, komunikasi jadi manual

1. Gaya tidak bocor

Shell memakai latar gelap. Remote memakai latar krem dan heading serif. Tidak ada aturan CSS shell yang mengubah tombol di dalam iframe.

2. DOM tidak bisa disentuh

Tekan Coba akses DOM shell di remote. Browser akan menolak akses karena dokumen remote berjalan di origin opaque.

3. Semua lewat pesan

Tidak ada import fungsi atau state bersama. Shell dan remote hanya bertukar objek JSON lewat postMessage, dan masing-masing harus memvalidasi bentuk pesan.
